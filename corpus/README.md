# Put your own device exports here

Export presets from HX Edit into this folder. The toolkit learns your device's
number formatting from them, and cannot write a safe .hsp without it.

See ../docs/SETUP.md step 3. Thirty or more gives good coverage.

Only files the DEVICE wrote belong here. Do not add presets this toolkit
generated: the learner would read your own mistakes back as ground truth.

Contents are gitignored. Your presets stay yours.
